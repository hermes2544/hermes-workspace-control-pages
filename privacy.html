Privacy Policy

Hermes Workspace Control Private is a personal, single-user automation utility. It accesses Google account data only after explicit authorization by the account owner.

Data use

Authorized data is used only to perform owner-requested tasks such as sending system reports, managing personal documents, calendars, contacts, spreadsheets, and backups. Data is not sold, shared for advertising, or used for profiling.

Storage and security

OAuth credentials are stored locally on the owner's private system with restricted file permissions. The utility does not operate a public user database.

Retention and deletion

The owner controls retained files and may revoke access at any time from Google Account security settings. Removing the local OAuth credential ends automated access.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
